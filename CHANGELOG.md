# 📋 Changelog

All notable changes to the **Abhiyantrix Smart Event Management Platform** are documented in this file.

## [1.0.0] - 2026-08-29

### 🚀 Added
- **Cryptographic HMAC-SHA256 QR Check-In:** Complete zero-trust check-in engine with hardware camera scanner, virtual self check-in, and tamper rejection.
- **Smart Team Matchmaking:** Bidirectional skill-gap query engine with real-time roster locking and capacity management.
- **Broadcast & Announcement Center:** Real-time WebSocket push with Web Audio API chime synthesis and priority filtering.
- **Interactive Judging Workspace:** Weighted rubric sliders (0–10), structured feedback submission, and live recalculation.
- **Dynamic Leaderboard:** Real-time podium view, rank movement deltas, tie-breaker logic, and criteria breakdown modal.
- **Executive Analytics:** Lifecycle conversion funnel (`Registered → Checked In → In Teams → Submitted`), check-in velocity timeline, and CSV report export.
- **Enterprise Security Hardening:** Helmet security headers, rate limiting (`express-rate-limit`), Zod input validation, and XSS sanitization.
- **Automated Verification:** 100% passing Vitest test suite and E2E verification test runner.
